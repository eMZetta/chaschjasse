Ton code de salon -----
  1. Télécharger l’app Pour iPhone et iPad dans l’App Store, pour Android en test sur Google Play. Gratuit, sans publicité, sans compte.

    Android : comment faire (en allemand)
  2. Ouvrir le jass en ligne Dans le menu principal de l’app, touche Jass en ligne, puis Rejoindre le salon.
  3. Saisir le code et jouer Saisis le code du salon (ou colle-le) – et te voilà à table.

Tu n’as pas besoin de créer de compte ni d’utiliser ton vrai nom. Plus d’informations sur le jass en ligne et la protection des données dans la déclaration de confidentialité.
